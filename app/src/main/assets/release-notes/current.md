## What's new

### A more comfortable writing space

- Medium editor text is larger, with more comfortable line spacing and padding.
- Tap anywhere on the writing canvas, including empty space, to focus the editor.
- Headings and code retain their styling as text size changes.

### Foldable workspace

- Fold preferences are part of Settings → Behavior.
- Choose whether a fold opens Reader metrics (Hemingway) or a second editor.
- Hinge recognition follows the Study Companion gesture, with optional haptics and paper sound.
- Settings shows local hinge readings. Close Settings before using the shortcut.

### Files and everyday polish

- Settings, file actions and recovery messages are more consistent.
- Drafts, selection and Undo remain intact when adapting the workspace.
- Each installed build adds this Markdown document under Files → Release Notes.

## About these notes

You can open, edit, move or share this document like any other Markdown file. Earlier notes and your edits are preserved. Deleting a note does not bring it back on every launch; a later build adds its own notes.
