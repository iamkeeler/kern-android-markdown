Privacy & Security

Privacy Policy

Kern stores your Markdown files where you choose. This policy explains file access, analytics, diagnostics, and deletion.

Your Markdown files

Kern reads and writes the files and folders you select in Android’s file picker. Kern does not upload your document contents to Kern-operated servers. If you select a cloud-backed folder, that storage provider controls the files.

File access

Kern uses Android’s Storage Access Framework to access the files and folders you select. Kern does not request broad device storage access.

Analytics and diagnostics

Kern uses Firebase Analytics and Crashlytics. Kern’s own analytics events record document opens, shares, and word and character counts. They do not include document titles, document text, or file paths.

Deletion and control

Delete, move, or back up your files from the storage location you choose. For questions about privacy requests, email gary@attach.design.

Contact

Email gary@attach.design with privacy questions.
