Privacy

Privacy note

Kern is being built as a local-first markdown reader and writing workspace for Android. This page is a plain-language privacy note for the pre-release website and app preparation work.

Local documents

Kern is designed to work with markdown files and folders you choose on your Android device. Your document content is not intended to be uploaded to Kern servers.

Analytics and diagnostics

The current release build includes Firebase Analytics dependencies. If Firebase Analytics remains enabled in the production build, Google/Firebase may collect app interaction, device, install/referrer, and diagnostic information for analytics.

Kern does not use this analytics path to upload the contents of your markdown documents. Before public release, this page should be updated to match the final Play Store Data Safety decisions.

Website

This static website does not require account creation. If it is later hosted with analytics or server logs, that hosting behavior should be documented here before launch.
