Privacy & Security

Privacy Policy

Kern is built as a local-first markdown reader and writing workspace for Android. This policy outlines our data posture, local file guarantees, and diagnostic practices.

Information you create in Kern

Kern is designed to work directly with markdown documents and folders you choose on your Android device. Your markdown files and document contents remain strictly local to your device or chosen cloud storage provider (e.g. Google Drive SAF folders) and are never uploaded to Kern-operated servers.

Local file access

Kern uses Android's Storage Access Framework (SAF) system file pickers to grant access to individual files or project directories. Application access is strictly constrained to the explicit document paths you select through standard system interfaces.

Analytics & diagnostics

Kern utilizes standard launch analytics (Firebase Analytics) to collect aggregated application interaction counters, device capabilities, and crash diagnostics to maintain software stability. Kern never transmits document titles, text contents, or file path metadata within diagnostic payloads.

Data deletion & control

Because Kern is local-first, all markdown files created or edited within Kern are stored on your local file system. You retain full control to delete, move, or backup your files at any time using any standard file manager.
