```bash

```

Note: the Hermes Python/PIL environment is currently broken for image generation, so use the ComfyUI venv Python for this script.

## Visual system

The graphics follow the Kern visual system from `design.md`:

- canvas: `#FCFBFA`
- surface: `#F4F3F0`
- warm icon background: `#ECEAE6`
- charcoal ink: `#1A1A18`
- muted steel: `#7C7A75`
- utility blue: `#2E5BFF`
- restrained typography-first composition

## Review notes

These are launch-readiness draft graphics. Before final public Play submission, replace or supplement them with real screenshots from a release-equivalent build if Google Play review requires exact in-app screenshots rather than designed store panels.
