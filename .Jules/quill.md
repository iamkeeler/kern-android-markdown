# Quill's Journal - Microcopy & Content Clarity Learnings

This journal tracks durable microcopy, terminology, and content clarity insights for the Kern project.

## 2026-07-24 - User-Facing Privacy Assurance vs Internal CI Credentials
**Learning:** Privacy band copy on landing pages often falls into the trap of describing internal developer security measures (e.g. "keeps sensitive credentials out of version control and uses explicit CI secrets") instead of stating plain user-facing value. Users care whether their documents leave their device, not how git repository secrets are managed.
**Action:** Lead with document sovereignty ("Your documents never leave your device") and zero cloud account requirements rather than internal build configuration details.

## 2026-07-24 - Concrete Actionable Feature Descriptions
**Learning:** Phrases like "is prepared for public GitHub releases with continuous CI distribution" use passive bureaucracy. Replacing them with concrete active statements ("Kern is fully open source on GitHub with automated releases") improves comprehension speed and trust.
**Action:** Default to active voice and concrete outcomes for feature lists and product headlines.
